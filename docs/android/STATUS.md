- Elision (per OCCURRENCE: a submission, an answer, or a dispute marker re-sending the sketch): an occurrence rides as a text stub (`sketchStubText`, label first) once a clean, doubt-free `read_sketch` follows it AND its scope has closed (a clean problem pose / a later non-dismissed question answer after it). The 20-page window stays as a backstop.

Regression test: a fresh process whose replay carried the sketch as a stub still gets the page with the dispute, on the same pid.
